# Shape Documentation

Predictable UI components for Laravel and Livewire. The pages below are in reading order — start
at the top on a fresh install, or jump to the component you are building with.

1. [Installation](installation.md) — the installer, the theme import, an icon set, and the publish tags
2. [Components](components.md) — the `shape:` tag prefix and a catalogue of everything Shape ships
3. [Button](components/button.md) — variant, color and size, icons either side, the loading state
4. [Input](components/input.md) — the text field, invalid states, icons, prefixes and suffixes
5. [Field](components/field.md) — the composition primitive and its label, legend, description and error parts
6. [Select](components/select.md) — a native `<select>` in the input's box, with a chevron
7. [Textarea](components/textarea.md) — the box around a control that stretches, and `autosize`
8. [Checkbox](components/checkbox.md) — the box, the row it sits in, and groups built from a field
9. [Radio](components/radio.md) — the checkbox made round, and why it never prints its own message
10. [Switch](components/switch.md) — the checkbox as a pill, for settings that apply when flipped
11. [File](components/file.md) — the control that arrives with a button already inside it
12. [Range](components/range.md) — a slider on the input's heights, with no box around it
13. [Color](components/color.md) — the native picker as a square swatch
14. [Icon](components/icon.md) — the component, for the places a prop cannot say it
15. [Icons](icons.md) — publishing icons, sets, semantic names, accessibility, and the five commands
16. [Theming](theming.md) — colour roles, surface tokens, page surfaces, adding a role, dark mode
17. [Configuration](configuration.md) — component defaults in `config/shape.php`
18. [Performance](performance.md) — what Blaze does with these components, and what folds
19. [Style Guide](STYLE_GUIDE.md) — the design guidance the components are built to

Every page carries previous and next links back to this list, so the whole set reads end to end.
